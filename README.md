# Mine Metro AP Set-Up Guide

- Archipelago
- The Mini Metro AP World
- Mini Metro (Can be bought on Steam)

# Installation

Installation is simple! Just unzip the Archipelago Mod into the Mini Metro Folder. You can find your local files by going to your Games Settings -> Manage -> Browse Local Files.

This build already has BepinEx installed and configured so everything should work smoothly!

# Connection

In the top left corner, you will see the archipelago login, put in your host name and your name and you will be able to connect to the game. Closing the game will disconnect you from the server and reconnecting will allow you to resume where you left off

*DISCLAIMERS:*
- Make sure you don't have any games that you can resume before entering the game.
- Alongside this, do not interact with the Steam Workshop or the Daily Challenge as these are connected to the Archipelago.

# Known Issues
